# 🚗 تطبيق أتينزا | Atenza App (Workshop Management System)

**Atenza App** هو نظام سحابي وهجين متكامل لإدارة ورش ومراكز صيانة السيارات. يربط النظام بين الإدارة، موظفي الكشف، الفنيين، والعملاء عبر واجهات حديثة ونظام صلاحيات متقدم، كروت تشغيل، متابعة سيارات المركز، وسجل تسعيرات متطور.

يدعم النظام الآن العمل المباشر مع **قواعد بيانات MySQL المدارة والسحابية (Hosted MySQL Database)** لتوفير استقرار وحفظ دائم للبيانات في بيئات الاستضافة والحاويات (Containers)، مع إمكانية العمل المحلي التلقائي عبر SQLite.

---

## 🌟 أبرز التحديثات والميزات الجديدة (v5.0)

### 1. 🗄️ دعم قواعد بيانات MySQL المدارة والسحابية (Hosted MySQL)
* **استقرار وحفظ دائم للبيانات:** ربط النظام بتجمع اتصالات (Connection Pooling) عالي الأداء مع MySQL عبر مكتبة `mysql2/promise`.
* **توافق تام مع بيئات الحاويات والاستضافة السحابية:** دعم منصات مثل AiroApp، Render، Railway، وcPanel دون فقدان أي بيانات عند إعادة تشغيل الحاويات.
* **تهيئة وهجرة تلقائية (Auto Schema & Migration):** يقوم النظام عند الإقلاع بإنشاء كافة الجداول وترحيل الحقول تلقائياً، مع نقل البيانات السابقة من ملف SQLite الافتراضي فورياً في حال كانت قاعدة MySQL فارغة.
* **مرونة العمل المحلي (Offline Fallback):** في حال عدم توفر متغيرات بيئة MySQL، يعمل النظام تلقائياً وبسلاسة على قاعدة بيانات SQLite المحلية دون أي تعطل.

### 2. 📋 نظام التسعيرات وكروت أوامر العمل (Quotations & Job Cards)
* **تحويل بنقرة واحدة:** إمكانية تحويل التسعيرة / الكشف الفني فورياً إلى **أمر عمل (Job Order / Job Card)** بضغطة زر.
* **مخطط صدمات وعيوب السيارة:** رسم تفاعلي لتحديد أماكن الصدمات والخدوش وتوقيع العميل الإلكتروني.
* **طباعة احترافية:** نماذج A4 منسقة ومجهزة للطباعة المباشرة أو الحفظ كـ PDF.

### 3. 🚗 لوحة متابعة سيارات المركز (Live Workshop Tracker)
* **متابعة حية للسيارات:** عرض فوري لجميع السيارات المتواجدة داخل الورشة مع عدادات وحالات تشغيلية.
* **تحديث فوري للحالات:** تغيير حالة السيارة مباشرة (`قيد الانتظار` ⏳، `جاري العمل` ⚙️، `بانتظار قطع غيار` 📦، `جاهزة للتسليم` ✅، `تم التسليم` 🏁).
* **تعيين الفنيين المسؤولين:** إسناد أوامر العمل للفنيين والكهربائيين والميكانيكيين المعنيين.

### 4. 🏗️ إدارة الرافعات (Workshop Lifts Management)
* **شاشة مراقبة تفاعلية للرافعات (`lifts.html`):** متابعة حالة الرافعات وتعيين الفني المسؤول عن كل رافعة.
* **تحديث فوري وإخلاء سريع:** أزرار لتحديث حالة الرافعة أو إخلائها بنقرة واحدة.

### 5. 👥 إدارة واستيراد العملاء (Clients Management)
* **سجل متكامل للعملاء (`clients_manager.html`):** بحث فوري بالاسم أو رقم الجوال، وتصحيح تلقائي لصيغ أرقام الهواتف السعودية والدولية.
* **استيراد من ملفات الإكسل:** إمكانية استيراد وتحديث آلاف سجلات العملاء بضغطة زر واحدة.

### 6. 📅 سجل التسعيرات السابقة والفلترة الزمنية
* **فلترة متقدمة بالتاريخ:** اختيار الفترات الزمنية بدقة مع أزرار سريعة (`اليوم`، `أمس`، `هذا الأسبوع`، `هذا الشهر`، `الكل`).
* **إحصائيات KPI:** رصد فوري لإجمالي المبالغ، عدد التسعيرات، ونسبة التحويل إلى أوامر عمل.
* **طباعة وإعادة فتح:** إمكانية إعادة طباعة أي تسعيرة قديمة أو تعديلها.

### 7. 🛡️ نظام الصلاحيات المتقدم (Role-Based Permissions)

### 8. 💬 أتمتة الواتساب وبوابة تتبع العميل المباشرة (WhatsApp & Live Tracking)
* **إرسال بنقرة واحدة:** إرسال كشف التسعيرة، إشعار بدء العمل، أو إشعار جاهزية السيارة مباشرة للعميل عبر الواتساب مع رابط مباشر.
* **بوابة العميل المباشرة (`track.html`):** صفحة تفاعلية مخصصة للجوال تمكّن العميل من متابعة مراحل الصيانة خطوة بخطوة، بنود الفحص، الصور المرفقة، والمبالغ دون الحاجة لتسجيل دخول.

### 9. 📸 التوثيق المرئي بالصور من الجوال (Before & After Photos)
* **التقاط صور من الكاميرا مباشرة:** دعم رفع وتصوير السيارة عند الاستلام، وتوثيق القطع التالفة، والصور بعد انتهاء الصيانة.
* **ربط الصور بكرت العمل:** تظهر الصور في كرت التشغيل الداخلي وفي بوابة العميل الخارجية.

### 10. ☑️ قائمة فحص البنود المنجزة لقسم المكانيكا والكهرباء (Service Checklist)
* **تأشير بنقرة واحدة:** تمكين فنيي المكانيكا والكهرباء من تأشير كل خدمة بمجرد إنجازها داخل كرت العمل `job_order.html`.
* **توثيق الفني والوقت:** تسجيل اسم الفني المنفذ وتوقيت الإنجاز الدقيق لكل بند صيانة.
* **شريط تقدم حي:** رصد نسبة إنجاز صيانة السيارة لحظياً (مثلاً `3 من 4 خدمات مكتملة 75%`).

## 🏷️ تغيير اسم وهوية التطبيق من مكان واحد (App Renaming)

يمكنك تغيير اسم وهوية التطبيق في أي وقت بكل سهولة:
1. **من واجهة الإعدادات داخل المتصفح (موصى به):**
   - ادخل إلى **⚙️ الإعدادات** (`settings.html`).
   - في قسم **📱 هوية واسم التطبيق**، قم بتعديل الاسم واضغط **حفظ كافة الإعدادات**.
   - يتم التحديث فوراً في جميع الصفحات، شاشات الدخول، الشريط الجانبي، وعناوين الكشوفات.
2. **من ملف الإعدادات المركزي (`public/js/app-config.js`):**
   - عدل قيمة `DEFAULT_APP_NAME` إلى الاسم المطلوب.

## ⚙️ إعداد متغيرات البيئة (Environment Variables)

عند النشر على منصات الاستضافة السحابية، يتم حقن إعدادات قاعدة بيانات MySQL عبر متغيرات النظام التالية (راجع ملف `.env.example`):

```env
PORT=8080
NODE_ENV=production

# إعدادات قاعدة بيانات MySQL المدارة
DB_HOST=your_database_host
DB_PORT=3306
DB_NAME=your_database_name
DB_USER=your_database_user
DB_PASSWORD=your_database_password
```

*(إذا لم يتم ضبط `DB_HOST`، سيعمل التطبيق تلقائياً عبر قاعدة بيانات SQLite المحلية `db.sqlite`).*

## 🚀 طريقة التثبيت والتشغيل

### 1. المتطلبات الأساسية
* تأكد من تثبيت [Node.js](https://nodejs.org/) (الإصدار 18 أو أحدث).

### 2. تثبيت الحزم
```bash
npm install
```

### 3. تشغيل الخادم
```bash
node server.js
```
أو عبر النقر المزدوج على ملف `start.bat`.

### 4. الدخول للنظام
افتح المتصفح على: `http://localhost:8080`

## 📁 هيكلية الصفحات الرئيسية

* `login.html` : صفحة تسجيل الدخول الموحدة.
* `admin.html` : لوحة تحكم المدير العام والإحصائيات وإدارة الموظفين والرواتب.
* `employee.html` : لوحة الموظف (تسجيل الحضور، الإجازات، السحوبات، والوصول السريع).
* `inspector.html` : محرر التسعيرات، الكشوفات الفنية، وأوامر العمل.
* `inspections_list.html` : سجل التسعيرات السابقة والفلترة بالتاريخ والطباعة.
* `job_orders_list.html` : لوحة سيارات المركز الحالية وأوامر العمل المفتوحة.
* `job_order.html` : كرت التشغيل ومخطط الصدمات وتوقيع العميل.
* `clients_manager.html` : إدارة والبحث في سجلات العملاء واستيرادهم.
* `services_manager.html` : إدارة أسعار وباقات الخدمات الفردية.
* `shortcuts_manager.html` : إدارة باقات واختصارات الكشف السريعة.
* `lifts.html` : شاشة متابعة وإشغال رافعات الورشة.
* `income_report.html` : تقارير الدخل المفصلة وإحصائيات الأداء وتصدير إكسل.
* `settings.html` : إعدادات النظام، جدول الدوام، وشروط الكشف.
* `track.html` : بوابة متابعة العميل لحالة السيارة وتطور الصيانة.

## 🛠️ التقنيات المستخدمة
* **Frontend:** HTML5, CSS3, JavaScript (Vanilla ES6+), PWA.
