# 📘 دليل المطور الشامل - نظام إدارة الورشة (Workshop Manager)

هذا المستند يعتبر المرجع الأساسي والتقني لتطوير وصيانة "نظام إدارة الورشة". تم إعداد هذا الدليل لضمان **توحيد الثيم**، **قابلية التطوير**، **استقرار النظام**، وتوفير **أدوات تقارير قوية**.

## � المميزات الحالية (Features)
### 👨‍💼 لوحة الإدارة (Admin Panel)
*   **إدارة الموظفين:** إضافة، تعديل، وحذف الموظفين (مع Soft Delete).

*   **المحادثة:** التواصل مع الإدارة.

### 🔍 نظام الكشف (Inspector System)
*   **إنشاء الكشوفات:** إصدار تسعيرات.
*   **البحث:** البحث برقم اللوحة أو الجوال.
*   *(ملاحظة: هذا القسم يحتاج لتطوير ميزات التعديل وحذف الكشوفات).*

## 🛠️ التقنيات المستخدمة (Tech Stack)
لضمان استقرار المشروع وعدم "تحطمه" (Crashing)، يجب الالتزام بالتقنيات التالية:

*   **Backend:** Node.js + Express.js
*   **Database:** SQLite (`db.sqlite`)
*   **Frontend:** Vanilla HTML/CSS/JS (بدون Frameworks ثقيلة).
*   **Libraries:** `xlsx` (للتقارير), `multer` (للملفات).

## 🎨 نظام التصميم الموحد (Unified Design System)
لضمان شكل **موحد وجذاب**، يجب استخدام ملف `style.css` كمصدر وحيد للتنسيق.

### 1. الألوان والمتغيرات
تم تعريف المتغيرات التالية في `style.css` ويجب استخدامها بدلاً من الألوان الثابتة:

## 📊 نظام التقارير والتصدير
### 1. تصدير Excel
المكتبة `xlsx` مثبتة بالفعل في المشروع. لاستخدامها في الباك إند:
```javascript
// في server.js
app.get('/api/export/report', async (req, res) => {
    const data = await dbAll("SELECT * FROM entries");
    const wb = xlsx.utils.book_new();
    const ws = xlsx.utils.json_to_sheet(data);
    xlsx.utils.book_append_sheet(wb, ws, "Report");
    const buf = xlsx.write(wb, { type: 'buffer', bookType: 'xlsx' });
    res.setHeader('Content-Disposition', 'attachment; filename="report.xlsx"');
    res.send(buf);
});
```

### 2. تصدير PDF
استخدم خاصية الطباعة في المتصفح مع تنسيقات `@media print` الموجودة في `style.css` لإخفاء القوائم والأزرار.

## 🔄 إدارة البيانات (CRUD)
لضمان أن المعلومات قابلة للتعديل والحذف:
*   تأكد من وجود زر "تعديل" و "حذف" لكل عنصر في القوائم.
*   **تنبيه:** نظام "الكشف" (Inspections) حالياً يفتقد لميزة الحذف والتعديل (`DELETE`, `PUT`). يجب إضافتها في `server.js` لتكتمل الميزات.
