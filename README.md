# 🚗 تطبيق أتينزا | Atenza App (Workshop Management System)

**Atenza App** هو نظام سحابي وهجين متكامل لإدارة ورش ومراكز صيانة السيارات. يربط النظام بين الإدارة، موظفي الكشف، الفنيين، والعملاء عبر واجهات حديثة ونظام صلاحيات متقدم، كروت تشغيل، متابعة سيارات المركز، وسجل تسعيرات متطور.

---

## 🌟 أبرز التحديثات والميزات الجديدة (v5.0)

### 1. 📋 نظام التسعيرات وكروت أوامر العمل (Quotations & Job Cards)
* **تحويل بنقرة واحدة:** إمكانية تحويل التسعيرة / الكشف الفني فورياً إلى **أمر عمل (Job Order / Job Card)** بضغطة زر.
* **مخطط صدمات وعيوب السيارة:** رسم تفاعلي لتحديد أماكن الصدمات والخدوش وتوقيع العميل الإلكتروني.
* **طباعة احترافية:** نماذج A4 منسقة ومجهزة للطباعة المباشرة أو الحفظ كـ PDF.

### 2. 🚗 لوحة متابعة سيارات المركز (Live Workshop Tracker)
* **متابعة حية للسيارات:** عرض فوري لجميع السيارات المتواجدة داخل الورشة مع عدادات وحالات تشغيلية.
* **تحديث فوري للحالات:** تغيير حالة السيارة مباشرة (`قيد الانتظار` ⏳، `جاري العمل` ⚙️، `بانتظار قطع غيار` 📦، `جاهزة للتسليم` ✅، `تم التسليم` 🏁).
* **تعيين الفنيين المسؤولين:** إسناد أوامر العمل للفنيين والكهربائيين والميكانيكيين المعنيين.

### 3. 📅 سجل التسعيرات السابقة والفلترة الزمنية
* **فلترة متقدمة بالتاريخ:** اختيار الفترات الزمنية بدقة مع أزرار سريعة (`اليوم`، `أمس`، `هذا الأسبوع`، `هذا الشهر`، `الكل`).
* **إحصائيات KPI:** رصد فوري لإجمالي المبالغ، عدد التسعيرات، ونسبة التحويل إلى أوامر عمل.
* **طباعة وإعادة فتح:** إمكانية إعادة طباعة أي تسعيرة قديمة أو تعديلها.

### 4. 🛡️ نظام الصلاحيات المتقدم (Role-Based Permissions)

### 5. 💬 أتمتة الواتساب وبوابة تتبع العميل المباشرة (WhatsApp & Live Tracking)
* **إرسال بنقرة واحدة:** إرسال كشف التسعيرة، إشعار بدء العمل، أو إشعار جاهزية السيارة مباشرة للعميل عبر الواتساب مع رابط مباشر.
* **بوابة العميل المباشرة (`track.html`):** صفحة تفاعلية مخصصة للجوال تمكّن العميل من متابعة مراحل الصيانة خطوة بخطوة، بنود الفحص، الصور المرفقة، والمبالغ دون الحاجة لتسجيل دخول.

### 6. 📸 التوثيق المرئي بالصور من الجوال (Before & After Photos)
* **التقاط صور من الكاميرا مباشرة:** دعم رفع وتصوير السيارة عند الاستلام، وتوثيق القطع التالفة، والصور بعد انتهاء الصيانة.
* **ربط الصور بكرت العمل:** تظهر الصور في كرت التشغيل الداخلي وفي بوابة العميل الخارجية.

### 7. 🔔 الإشعارات الحية التفاعلية والتنبيه الصوتي (Real-time Live Alerts)
* **تنبيه فوري للفنيين:** إشعار صوتي ومرئي فوري في شاشة الفني عند تعيين أمر عمل جديد له.
* **تنبيه الإدارة عند جاهزية السيارة:** إشعار الإدارة فور تحويل حالة السيارة إلى `جاهزة للتسليم ✅`.

### 8. 🧭 التنقل الذكي وشريط القوائم الموحد (Smart Navigation & Navbar)
* **زر رجوع ذكي (`APP_NAV.goBack`):** يضمن العودة للصفحة السابقة دون الخروج من البرنامج أو فقدان الجلسة.
* **شريط علوي موحد (`#atenzaNavbar`):** شريط تنقل متكيف يظهر في أعلى جميع الصفحات ويعرض الروابط المتاحة للمستخدم وفقاً لصلاحياته.

## 🏷️ تغيير اسم وهوية التطبيق من مكان واحد (App Renaming)

يمكنك تغيير اسم وهوية التطبيق في أي وقت بكل سهولة:
1. **من واجهة الإعدادات داخل المتصفح (موصى به):**
   - ادخل إلى **⚙️ الإعدادات** (`settings.html`).
   - في قسم **📱 هوية واسم التطبيق**، قم بتعديل الاسم واضغط **حفظ كافة الإعدادات**.
   - يتم التحديث فوراً في جميع الصفحات، شاشات الدخول، الشريط الجانبي، وعناوين الكشوفات.
2. **من ملف الإعدادات المركزي (`public/js/app-config.js`):**
   - عدل قيمة `DEFAULT_APP_NAME` إلى الاسم المطلوب.

## 🚀 طريقة التثبيت والتشغيل

### 1. المتطلبات الأساسية
* تأكد من تثبيت [Node.js](https://nodejs.org/) (الإصدار 18 أو أحدث).

### 2. تثبيت الحزم
```bash
npm install
```

### 3. تشغيل الخادم
```bash
node server.js
```
أو عبر النقر المزدوج على ملف `start.bat`.

### 4. الدخول للنظام
افتح المتصفح على: `http://localhost:8080`

## 📁 هيكلية الصفحات الرئيسية

* `admin.html` : لوحة تحكم المدير العام والإحصائيات وإدارة الموظفين والرواتب.
* `employee.html` : لوحة الموظف (تسجيل الحضور، الإجازات، السحوبات، والوصول السريع).
* `inspector.html` : محرر التسعيرات، الكشوفات الفنية، وأوامر العمل.
* `inspections_list.html` : سجل التسعيرات السابقة والفلترة بالتاريخ والطباعة.
* `job_orders_list.html` : لوحة سيارات المركز الحالية وأوامر العمل المفتوحة.
* `job_order.html` : كرت التشغيل ومخطط الصدمات وتوقيع العميل.
* `services_manager.html` : إدارة أسعار وباقات الخدمات.
* `income_report.html` : تقارير الدخل المفصلة وإحصائيات الأداء وتصدير إكسل.
* `settings.html` : إعدادات النظام واسم التطبيق وهوية الورشة.
