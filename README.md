# 🛠️ نظام إدارة الورشة (Workshop Manager v2)

نظام متكامل لإدارة ورش الصيانة، يتيح للمدير متابعة الموظفين، الدخل، السحوبات، والرافعات، ويوفر للموظفين واجهة لتسجيل الحضور، طلب الإجازات، ومتابعة أهدافهم، بالإضافة إلى نظام كشف فني متطور.

## ✨ المميزات الرئيسية

### 👨‍💼 لوحة الإدارة (Admin Panel)
*   **إدارة الموظفين:** إضافة، تعديل، وحذف الموظفين مع تحديد الأهداف والرواتب.
*   **متابعة الدخل:** لوحة قيادة (Dashboard) تعرض إجمالي الدخل، السحوبات، ونسبة تحقيق الأهداف لكل قسم.
*   **إدارة الطلبات:** قبول أو رفض طلبات الإجازة والسحوبات المالية المعلقة.
*   **نظام المحادثة:** التواصل المباشر مع الموظفين عبر نظام شات مدمج.
*   **إدارة الرافعات:** مراقبة حالة رافعات الورشة وتعيين الفنيين عليها.
*   **إدارة الخدمات:** نظام مركزي لإدارة الخدمات والأسعار وتصنيفها.
*   **التقارير:** تقارير تفصيلية عن الدخل والغياب مع إمكانية التصدير.

### 👷 لوحة الموظف (Employee Panel)
*   **تسجيل الحضور:** نظام تسجيل دخول وخروج (Check-in/Check-out) يحاكي البصمة.
*   **متابعة الأداء:** عرض نسبة تحقيق الهدف الشهري والدخل الحالي.
*   **الطلبات:** تقديم طلبات إجازة أو سحب مالي ومتابعة حالتها.
*   **المحادثة:** التواصل مع الإدارة.
*   **تنبيهات الرافعات:** شريط تنبيهات يعرض حالة الرافعات المتاحة أو المتوقفة.
*   **تطبيق ويب تقدمي (PWA):** إمكانية تثبيت التطبيق على الهاتف والعمل بوضع ملء الشاشة.

### 🔍 نظام الكشف الفني (Inspector System)
*   **إنشاء الكشوفات:** إصدار تقارير فنية وتسعيرات أجور بشكل احترافي.
*   **الطباعة و PDF:** تنسيق مخصص للطباعة يضمن ظهور البيانات بشكل منظم ومهني.
*   **البحث الذكي:** إمكانية البحث عن الكشوفات السابقة برقم الكشف، رقم الجوال، أو رقم اللوحة.
*   **الإضافة السريعة:** واجهة مخصصة للجوال لإضافة الخدمات بسرعة وسهولة.

## 🚀 طريقة التشغيل

1.  **تثبيت المتطلبات:**
    تأكد من تثبيت [Node.js](https://nodejs.org/) على جهازك.

2.  **تثبيت الحزم:**
    افتح موجه الأوامر (Terminal) في مجلد المشروع ونفذ الأمر:
    ```bash
    npm install
    ```

3.  **تشغيل السيرفر:**
    ```bash
    node server.js
    ```
    أو ببساطة اضغط مرتين على ملف `start.bat`.

4.  **الدخول للنظام:**
    افتح المتصفح على الرابط: `http://localhost:8080`

## 🔐 بيانات الدخول الافتراضية

*   **المدير:**
    *   اسم المستخدم: `admin`
    *   كلمة المرور: `admin123`

*   **الموظف:**
    *   يتم إنشاء حسابات الموظفين من خلال لوحة الإدارة.

## 🛠️ التقنيات المستخدمة
*   **Frontend:** HTML5, CSS3 (Modern Variables), JavaScript (Vanilla).
*   **Backend:** Node.js, Express.js.
*   **Database:** SQLite (ملف `db.sqlite`).
*   **PWA:** Service Workers, Manifest.json.
*   **Charts:** Chart.js.

## 📱 دعم الهاتف (PWA)
يدعم النظام التثبيت كتطبيق على الهواتف الذكية (Android/iOS) ويوفر تجربة استخدام شبيهة بالتطبيقات الأصلية مع دعم العمل بدون اتصال للبيانات المخزنة مؤقتاً.
