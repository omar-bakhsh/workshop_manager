بوابة ربط تطبيق الأندرويد والـ API (Android Mobile REST API)
RESTful JSON API لكافة بيانات الورشة مع دعم كامل (PULL, PUSH, EDIT, DELETE, SYNC)
متصل ويعمل v1.0 JSON

تتيح لك هذه الواجهة ربط تطبيق الأندرويد (Android App) بكافة جداول قاعدة بيانات الورشة (أوامر العمل، العملاء، الموظفين، الصندوق اليومي، والخدمات) مع إمكانية القراءة (PULL)، الإضافة (PUSH)، التعديل (EDIT)، الحذف (DELETE)، والمزامنة الدفعية للمركبات بدون اتصال.

عند إلغاء التفعيل، سيتم حجب كافة طلبات الربط الخارجية من أجهزة وتطبيقات الأندرويد لأمان النظام.
• للمحاكي (Android Emulator): http://10.0.2.2:8080/api/v1
يتم إرساله مع كل طلب أندرويد في الـ Header أو كـ Query Parameter باسم api_key.

دليل الذكاء الاصطناعي لربط الـ API وتطبيق React Native Expo (AI Prompt & Guide) جاهز للـ AI

دليل شامل ومُهندس بالكامل لتقديمه لأي مساعد ذكاء اصطناعي (ChatGPT, Claude, Gemini, Cursor) ليتعرف على كافة الجداول الـ 27، عناوين الاتصال، المفتاح السري، وبناء تطبيق الجوال عبر (React Native Expo / TypeScript / Axios / Expo SQLite) بكفاءة تامة.

                             مثال كود React Native Expo (TypeScript / Axios):
                        
                        
                    

                    
// Atenza Workshop API Client (React Native Expo - TypeScript & Axios)
import axios from 'axios';

// Configure Base URL: Physical Device via Wi-Fi or Emulator (10.0.2.2)
const API_BASE_URL = 'http://192.168.8.112:8080/api/v1';
const API_KEY = 'atenza_apk_...'; // From Settings

export const apiClient = axios.create({
  baseURL: API_BASE_URL,
  timeout: 15000,
  headers: {
    'Content-Type': 'application/json',
    'x-api-key': API_KEY,
  },
});

export const AtenzaApi = {
  // 1. Health Ping
  ping: () => apiClient.get('/ping'),

  // 2. PULL: List records with filters and pagination
  getRecords: (table: string, params = {}) =>
    apiClient.get(`/db/${table}`, { params }),

  // 3. PULL ONE: Get single record by ID
  getRecordById: (table: string, id: string | number) =>
    apiClient.get(`/db/${table}/${id}`),

  // 4. PUSH: Create new record
  createRecord: (table: string, data: any) =>
    apiClient.post(`/db/${table}`, data),

  // 5. EDIT: Update existing record
  updateRecord: (table: string, id: string | number, data: any) =>
    apiClient.put(`/db/${table}/${id}`, data),

  // 6. DELETE: Remove record
  deleteRecord: (table: string, id: string | number) =>
    apiClient.delete(`/db/${table}/${id}`),

  // 7. SYNC PULL: Pull changes since timestamp for offline storage (Expo SQLite / AsyncStorage)
  pullFullSync: (since?: string, tables?: string) =>
    apiClient.get('/sync/pull', { params: { since, tables } }),

  // 8. SYNC PUSH: Batch sync offline changes back to server
  pushBatchSync: (tablesPayload: Record<string, any[]>) =>
    apiClient.post('/sync/push', { tables: tablesPayload }),
};
