🔔 نظام الإشعارات

اضغط على الأزرار لتجربة أنواع مختلفة من الإشعارات

📝 كيفية الاستخدام:

// إشعار نجاح
showSuccess('تم الحفظ بنجاح');

// إشعار خطأ
showError('فشلت العملية');

// إشعار تحذير
showWarning('يرجى الانتباه');

// إشعار معلومة
showInfo('معلومة مفيدة');

// أو استخدام الدالة العامة
showToast('رسالة مخصصة', 'success', 3000);
